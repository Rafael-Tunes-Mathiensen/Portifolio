# Símbolos das tecnologias

Os SVGs foram distribuídos pelo projeto [Devicon, versão 2.17.0](https://github.com/devicons/devicon/tree/54cfe13ac10eaa1ef817a343ab0a9437eb3c2e08). A [licença MIT original](LICENSE.txt) acompanha os arquivos. As marcas representam seus respectivos produtos.

Origem de cada arquivo no repositório Devicon: `icons/<nome>/<nome>-original.svg`. O símbolo Django usa a variante `icons/django/django-plain.svg`.
